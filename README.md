# OrderFlow MVP

Pixel-accurate Next.js recreation of the OrderFlow Stitch project.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Routes

- `/`
- `/dashboard`
- `/dashboard/orders`
- `/dashboard/products`
- `/dashboard/customers`
- `/dashboard/checkout`
- `/dashboard/analytics`
- `/dashboard/settings`

The app uses local mock data and has no backend dependency.
